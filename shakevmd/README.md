# shakevmd

カメラモーション VMD ファイルに手ぶれ効果を焼き込むツール。
指定しなければ元の VMD はそのまま残して、揺れを足した新しい VMD を作る。
手作業でカメラキーを増やさずに、MMD のカメラに手ぶれ効果を追加できる。

## 使い方

基本の形:

```sh
shakevmd INPUT.vmd [オプション]
```

例:

```sh
shakevmd camera.vmd -o camera_shake.vmd --range 120:360
```

## プリセット

| 名前 | 特徴 |
|---|---|
| `handheld` | 標準的な手ぶれ |
| `telephoto` | 望遠のようにゆっくり揺れる |
| `walking` | 歩き撮りのように上下が強く揺れる |
| `earthquake` | 地震のように強く揺れる |

## 知っておくこと

- `--range` の端は、近くの既存キーフレームに自動で寄る。途中フレームへ無理に割り込んで、元の動きが変わるのを避けるため。
- 手ぶれを入れる範囲の端では、自動でフェードイン・フェードアウトする。
- 既定では、出力をなめらかにする処理も行う。密なキーをそのまま出したい場合は `--no-smooth` を使う。
- 手ぶれを足すのは、カメラの動きを作り終えた最後にする。先に焼き込むとキーが増えて、あとからの手直しが難しくなる。

## オプション

`--preset` を使うと、揺れの強さや速さの既定値がプリセットの値に変わる。
そのうえで `--amp-rot` などを個別に指定すると、個別指定のほうが優先される。

### 入出力

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `INPUT.vmd` | 必須 | 入力するカメラモーション VMD ファイル。カメラキーが入っていない VMD は処理できない。 |
| `-o`, `--output PATH` | `<入力名>_shake.vmd` | 出力先。指定しない場合は、入力ファイルの名前に `_shake` を付けた VMD を作る。 |
| `--overwrite` | 無効 | 入力ファイルそのもの(同一パス)へ上書き出力することを許可する。指定しない場合、入力と同じファイルへ書こうとすると止まる。別名や別フォルダへの出力は指定不要。 |

### 揺れを入れる範囲

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `--range START:END` | 全範囲 | 揺れを入れるフレーム範囲。`120:360` なら 120 から 360 フレームを基準にする。`120:` で 120 から末尾まで、`:360` で先頭から 360 まで、`:` で全範囲。端は近くの既存キーフレームに自動で寄るため、実際の範囲が少し前後することがある。複数回指定できる。 |
| `--fade 秒` | `0.7` | 範囲の始まりと終わりで、揺れをフェードイン・フェードアウトする時間。大きくするとゆっくり入ってゆっくり抜ける。短い範囲では自動で短くなる。 |

### 揺れの種類と強さ

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `--preset NAME` | なし | `handheld` / `telephoto` / `walking` / `earthquake` から選ぶ。揺れの強さ、速さ、動いている時の弱まり方などを一括設定する。 |
| `--amp-rot VALUE` | `0.8` | 回転方向の揺れの強さ。単位は度。大きくすると視線の揺れが強くなる。`0` なら回転揺れなし。 |
| `--amp-pos VALUE` | `0.05` | 位置方向の揺れの強さ。MMD の距離単位。大きくするとカメラ位置の揺れが強くなる。上げすぎると酔いやすい絵になる。 |
| `--rot-weights P,Y,R` | `1.0,1.0,0.3` | Pitch(上下) / Yaw(左右) / Roll(傾き) の揺れの比率。3つの数値をカンマで指定する。既定では Roll を弱めにしている。 |
| `--freq VALUE` | `1.2` | 揺れの速さ。1秒あたり何回くらい揺れるかの目安。大きくすると細かく速い揺れ、小さくするとゆっくりした揺れになる。 |
| `--seed VALUE` | `1` | 乱数シード(揺れを作る乱数の初期値)。同じ入力と同じ設定なら同じ揺れになる。値を変えると、同じ強さでも別の揺れ方になる。 |
| `--motion-damp VALUE` | `1.0` | 元のカメラが大きく動いているところで揺れを弱める量。`0` なら弱めない。大きいほど動き中の揺れが控えめになる。 |
| `--settle VALUE` | `0.0` | カメラが止まった時に、少し余韻の揺れを足す強さ。単位は度。`0` なら使わない。 |
| `--impulse F:S:D` | なし | 指定フレームに衝撃のような揺れを足す。`F` はフレーム、`S` は強さ、`D` は減衰秒。例: `--impulse 180:2.0:0.5`。複数回指定できる。 |

プリセットで使われる主な値は次の通り。

| プリセット | 回転 | 位置 | 速さ | 動き中の弱め方 | 停止時の余韻 |
|---|---:|---:|---:|---:|---:|
| `handheld` | `0.9` | `0.06` | `1.3` | `1.0` | `0.4` |
| `telephoto` | `1.8` | `0.015` | `0.7` | `1.0` | `0.5` |
| `walking` | `1.0` | `0.18` | `2.0` | `0.3` | `0.3` |
| `earthquake` | `3.5` | `0.5` | `5.0` | `0.0` | `0.6` |

### カメラ切り替えと出力確認

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `--cut-threshold POS,ROT` | `5.0,20.0` | MMD のカメラでいう「カメラ切り替え」を見つける感度。隣り合うフレームのキーで、カメラ中心またはカメラのワールド位置の差が `POS`、角度の差が `ROT` を超えるところを、カメラが切り替わった場所として扱う。ここをまたいで揺れをなめらかにつなぐと、パッと切り替わるはずのカメラが変に移動したように見えるため、それを避けるための設定。 |
| `--smooth`, `--no-smooth` | `--smooth` | 既定では、焼き込んだ密なキーを、ベジェ補間を使って整理する。許容内に収まるところはキー数を減らし、許容を超えるところは必要なキーを残す。密なキーをそのまま出したい場合は `--no-smooth`。 |
| `--dry-run` | 無効 | VMD を出力せず、範囲、平滑化前のキー数(`--smooth` での整理はこの後に行うため、出力 VMD のキー数とは別の値)、見つけたカメラ切り替え、警告などを確認する。まず様子を見る時に使う。 |
| `--preview-csv PATH` | なし | フレームごとの揺れ量を CSV に出す。表計算ソフトやグラフで揺れ方を確認したい時に使う。 |
| `-v`, `--verbose` | 無効 | 詳細ログを表示する。指定した範囲がどの既存キーフレームへ寄ったか、処理の中身を追いたい時に使う。 |

さらに細かい仕様を確認したい場合は [shakevmd.md](shakevmd.md) を参照。
