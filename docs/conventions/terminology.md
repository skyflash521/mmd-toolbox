# 用語規約

ツール横断で守る用語の正記法を [禁止・注意表記](#禁止注意表記)と
[処理工程の利用者向け名称](#処理工程の利用者向け名称)の2表にまとめる。ドキュメントを編集したら、
編集箇所の表記を2表と照合し、例外規則と文脈で正否を判断する。節参照・ファイル相互参照の書き方は
[cross-references.md](cross-references.md) を正本とする。

## 禁止・注意表記

下表は候補列挙の基準であり、例外規則があるため機械的に違反と断定しない。文脈で正否を判断する。

| 禁止・注意表記 | 正 | 例外 |
|---|---|---|
| 補間カーブ、裸の「カーブ」 | 補間曲線 | なし |
| パースペクティブ(UI操作・データ作成手順の文脈) | パース | バイナリ仕様・データモデル記述では「パースペクティブフラグ」が正 |
| FOV | 視野角 | コード識別子 `fov` |
| 注視点、ターゲット | カメラ中心 | なし |
| カメラキー格納値としての「回転」 | 角度 | 補間チャンネル名の「回転」、回転行列・回転ノイズ等の一般用語は可 |
| モーフセクションの呼称としての「表情」 | モーフ | 表情モーフ(モーフの種類名)は可 |
| VMDの表情モーフ演出を指す「口パク」 | リップモーション | VMDと無関係な、一般的な意味での「口パク」は可 |
| セルフシャドウ | セルフ影 | 英語見出し Self Shadow は可 |
| 「足IK最適化」 | 足IK接地安定化 | 仕様書内部の略記「足IK安定化」は可 |
| 利用者向けの表面での「疎化」「疎ベジェ」 | [処理工程の利用者向け名称](#処理工程の利用者向け名称)の表の名称 | 仕様書・規約・コード内は「疎化」が正 |
| 工程名としての「平滑化」「クリーニング」「ノイズ除去」 | [処理工程の利用者向け名称](#処理工程の利用者向け名称)の表の名称(スムージング・ノイズ軽減 等) | 工程名以外の文脈(平滑化フィルタ等の機構説明、仕様書内部の総称「クリーニング」)は可 |
| 条件記述での「変更した」「変化する」等の基準点が不明瞭な語 | 観測可能な性質(「値が2種類以上ある」等) | 条件・手順以外の文脈は可 |
| MMM(MikuMikuMoving)への言及、「MMD/MMM」表記 | MMD(本プロジェクトの出力が対応する編集・確認環境はMMDのみ) | なし |
| CLIツール自身のバージョンを指す「版」(版番号・版付け・初版 等) | バージョン | ファイル形式の世代(旧版VMD)・ビルド/エディションの区別(CUDA版)・依存パッケージのバージョン・コード内の実装バリアント(簡略版 等)としての「版」は可(意味が異なるため) |

## 処理工程の利用者向け名称

複数のツールで共有されうる処理工程、または名称・stage id が衝突しうる処理工程を、利用者向けの表面
(README・`--help`・進捗表示の段ラベル・診断表示)で呼ぶ名称として下表に定義する。**単一ツールに
固有の工程(他ツールと共有せず、名称衝突の恐れも無い工程)は本表に登録せず、そのツール自身の仕様書に
名称を定義すればよい**(本表とツール仕様書の二重管理を避けるため)。下表に載る工程は、どのツールでも
同じ名称で呼び、同じ名称を別の工程の意味で使わない。stage id も同じ工程では同じ値を使うが、対象種別
ごとに分けて報告するツール(下表に個別の注記があるもの)は、対象ごとの id をそのツールの仕様書で
定めてよい。進捗の段ラベルは README・help の
工程名と一致させる。**本表に載る工程**の追加や名称変更は、先に本表を更新して既存の定義と衝突しない
ことを確認してから各ツールへ反映する(単一ツール固有の工程は本表を経由せず、そのツールの仕様書だけを
直接更新すればよい)。

| 名称 | 工程 | 対応オプション | 機械モード stage id |
|---|---|---|---|
| ベイク | 効果を計算して密キーへ焼き込む | (常に実行) | `bake` |
| スムージング | 密キーをベジェ補間へなめらかに整理する | `--smooth` / `--no-smooth` | `smooth` |
| ノイズ軽減 | 細かい揺れを抑える | `--denoise` / `--no-denoise` | `denoise` |
| 足IK接地安定化 | 接地中の足IKのぐらつき・横滑りを抑える | `--foot-ik-stabilize` / `--no-foot-ik-stabilize` | `foot_ik` |
| キーフレーム圧縮 | 許容誤差の範囲でキー数を減らす | `--reduce` / `--no-reduce` | `reduce`(対象種別ごとに分けて報告するツールは対象ごとの id をツール仕様書で定める) |
| 音声読み込み | 入力音声を読み込む | (常に実行) | `load` |
| ボーカル分離 | 伴奏からボーカルを分離する(分離方針が「分離しない」の場合は工程自体は進むが分離処理は行わない) | `--separate-vocals {always,never}` | `separate` |
| 音素認識 | ボーカルから音素・歌詞を認識する | (常に実行) | `recognize` |
| 音量解析 | ボーカルの時刻ごとの音量(RMS)を求める | (常に実行) | `rms` |
| 書き出し | 生成結果を出力ファイルへ書き出す | `--dry-run` 指定時は実行しない | `write` |
