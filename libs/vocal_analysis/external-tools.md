# vocal_analysis 外部ツールの制約

vocal_analysis が内部で使う外部ツールとモデルの、同梱と利用条件の制約。

- 本体の MIT ライセンスと両立しないライセンス(GPL など)のツールとモデルは使わない。
- ffmpeg はリポジトリに同梱も再配布もせず、利用者の環境にあるものを実行時に検出して使う。ffmpeg のビルドは
  LGPL または GPL で配布されている。
- SOFA は本体のコードもチェックポイントも同梱しない。SOFA の Python 依存(固定版の numpy・librosa など)は
  本リポジトリの実行環境と両立しない。SOFA を使う利用者は、SOFA の依存を入れた専用の Python 環境を用意する。
- SOFA のチェックポイントには既定値を設けない。入手できる日本語のチェックポイント(Greenleaf2001/SOFA_Models・
  colstone/SOFA_Models)は、いずれも商用利用が制限されている(前者は商用利用不可を明記し、後者は商用利用に
  個別の相談を要するコーパスを訓練データに含む)。指定したチェックポイントのライセンス条件を守るのは、それを
  指定する利用者である。
