# テストデータVMD

vmd・各ツールのテストが使用する、MMD産の検証用VMD。

---

## 方針

- このディレクトリに置くのは**MMD本体で作成したファイルのみ**
- 既知値が必要なテストデータ(カット入り・順不同・切り詰め・v1形式・
  混在セクション・ベイク済み・物理フラグ等)はファイルとして置かず、
  テストコード内のフィクスチャとして用意する
- フィクスチャは宣言的なリテラルに限る: io層のテストには手書きのバイト列、
  ロジックのテストには直接記述したキー列・文書。解析・オフセット計算・
  ファイルの加工といった、実行しないと出力が分からないロジックを含めてはならない
- MMD産ファイルを使うテストは内容の事前知識を必要としないものに限る:
  - ラウンドトリップ(read→write のバイト一致)
  - 補間・カメラ変換のクロスバリデーション入力
    (ファイルから読んだキーを評価して独立実装と比較)
  - 下記の条件を満たしているかの検査(テストデータ検査のテストが
    1条件=1テストとして検査し、満たさない場合は
    「テストデータの作り直しが必要」であることを明示して失敗する)
- 作成手順に正確なフレーム番号・数値の指定はない。
  条件は保存されたファイルの内容が満たすべき性質であり、条件にない事項(キーの位置、個々の値)は任意
- 作成・配置後に `pytest libs/vmd/tests` を実行すると、
  満たしていない条件がテスト名と失敗メッセージで列挙される。
  すべて成功すればデータは完成

## camera_basic.vmd

カメラ・照明モードで作成し、カメラ・照明モーションとして保存する
(カメラ・照明・セルフ影セクションが1ファイルに入る)。

- カメラキーが3個以上ある
- 2個目以降のカメラキーに、補間曲線がデフォルト値のキーが1個以上ある
- 2個目以降のカメラキーに、補間曲線がデフォルト値でないキーが1個以上ある
- 距離の値が2種類以上ある
- カメラ中心の座標(X・Y・Zの組)が2種類以上ある
- 角度(X・Y・Zの組)が2種類以上ある
- 視野角の値が2種類以上ある
- パースONのキーとOFFのキーの両方がある
- 照明キーが1個以上ある
- セルフ影キーが1個以上ある

補間曲線のデフォルト値は、全6チャンネルが (20, 107, 20, 107)(MMDがキー登録時に設定する線形の値)。

## model_motion.vmd

任意のモデルで作成し、モデルモーションとして保存する。

- ボーンキーが1個以上ある
- モーフキーが1個以上ある
