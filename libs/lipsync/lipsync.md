# lipsync — アニメ的リップモーションのモーフキー生成

層: **共有ドメイン層**([../../docs/conventions/layering.md §1](../../docs/conventions/layering.md#1-層タクソノミー))。

開き量を添えた口形イベント列から、標準口モーフ(あ・い・う・え・お・ん)による MMD 的なリップモーションの
モーフキー列を生成する。複数の CLI が同じコアとして使う。

## 品質要求

- 各口形は標準口モーフの重みの組として設計した合成で作り、フレームごとに無制御に混ぜない。
- 口を最大値まで開かない。標準的な発声で 0.5 前後、強い声で 0.8 前後、弱い声で 0.3 前後に収める。
- 横開き(い)と丸め(う・お)は、自然さの範囲で実物よりやや大きめに強調する。
- 各口形は短いアタックで開いてモーラ区間の大半を一定値で保ち、短いリリースか協調調音で次へ移る。保持中は
  フレーム単位で揺らさず、揺らぎは長く伸ばす音にだけ加える。
- 強弱はフレーム単位で追従せず、口形イベントごとの開き量で表す。
- 短いモーラで小刻みにパクつかせず、発声が続く間に口を閉じない。
- 同じ口形のモーラが続いても、顎の閉じを伴う子音による区切りは口の動きとして見せる。区切りが密に続くときは
  小刻みなパクつきを避けることを優先し、一部の区切りを見せない。
- キーは全フレームに置かず、要所にだけ置く。

## 対象範囲

- 入力の口形イベント列とその開き量は呼び出し側が確定する。音声認識や楽譜の解析、音量から開き量への写像、
  無音・両唇閉鎖・レガート間隙の区別、撥音「ん」の採否、子音種別の付与は持たない。
- 生成パラメータの具体値(プリセット)と CLI 引数は各ツールが持つ。
- 返すのはモーフキー列までで、VMD の組み立てと書き出しは呼び出し側が `vmd` で行う。
