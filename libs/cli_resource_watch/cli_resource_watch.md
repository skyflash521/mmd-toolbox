# cli_resource_watch 仕様書

層: **共有ドメイン層**([../../docs/conventions/layering.md §1](../../docs/conventions/layering.md#1-層タクソノミー))。

処理中の資源逼迫(GPU メモリの超過・スワップ)と、GPU を使えない実行構成を観測して判定し、成立した
警告のコードと観測値を返す。判定は観測できた値どうしの比較だけで行い、モデル・入力・機材ごとの需要
見積りを持たない。

## 対象範囲

- 警告の本文(利用者へ見せる文言と勧める対処)は組み立てない。
- 監視スレッドを持たず、判定を呼んだ時点の観測で判定する。スワップ使用量とプロセスツリーの使用量は
  呼び出し時点の値なので、呼び出しの間に増えて戻った逼迫は検出しない。
