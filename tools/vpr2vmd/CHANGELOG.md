# 変更履歴

## 0.0.2 - 2026-11-14

### 破壊的変更

- 機械利用: `warning` イベントの `section` を、文字列から配列へ変えた(`"morph"` を `["morph"]` に)。

### 追加

- 機械利用: `--describe` の各オプションに `repeat` を加えた。

### 変更

- 口蓋化した子音(`g'`・`4'`・`t'`・`d'`・`p\'`)にも、もとの子音と同じ口の動きを付けるようにした。
- `--coartic-overlap` の説明を「隣接母音のあいだで口形を移す長さ」に改めた。受け付ける値と既定は変わらない。
- `--help` で `-o`・`--overwrite`・`--dry-run`・`-v` を後ろへまとめた。
- 壊れたファイルを含む vpr、拍子の分母が負の vpr、`voices` が配列でない vpr を、`not_vpr`(終了コード1)で止めるようにした。

### 修正

- 口形の移り変わりが指定の長さを超えて延びていたのを直した。
