# vpr2vmd

VOCALOID のプロジェクトファイル(vpr)から、あ・い・う・え・お・(ん)のリップモーション VMD を
作るツール。モーラごとに口形を保持し、声の強弱を各モーラの口の開き量に反映する。

## 使い方

1. VOCALOID で保存した vpr ファイルを用意する。
2. 次のコマンドを実行する。

```sh
vpr2vmd <入力ファイル名>.vpr
```

生成したリップモーション VMD が、入力した vpr と同じフォルダに `<入力ファイル名>.vmd` という名前で
作られる。別の場所や名前にしたいときはオプション `-o` で出力先を指定する。

```sh
vpr2vmd <入力ファイル名>.vpr -o <出力ファイル名>.vmd --style powerful
```

追加のインストールは要らない。トップ [README.md の 4. 仮想環境を作成する](../../README.md#4-仮想環境を作成する)
で作った環境で実行できる。

使えるオプションの一覧と短い説明は `vpr2vmd --help` で確認できる。

## 歌い方スタイルプリセット

`--style` で、歌い方に合わせて口の開き量やタイミングの既定値をまとめて切り替えられる。

| 名前 | 想定する歌い方 |
|---|---|
| `pop`(既定) | 標準的・はっきりした歌唱 |
| `ballad` | しっとり・落ち着いた歌唱 |
| `powerful` | 力強い・ロック・シャウト |
| `whisper` | ささやき・静かな歌唱 |
| `rap` | 早口・テンポの速い歌唱 |

プリセットは出発点で、`--open-max` などの個別の[オプション](#オプション)で上書きできる。

## 口の開き量の決まり方

各モーラの開き量は次の順で決まる。

1. vpr に声量のコントローラ曲線(DYN)があれば、その値から決める。
2. 声量のコントローラ曲線が無ければ、音符のベロシティ(0〜127)から決める。
3. ベロシティが一様で強弱の差が無ければ、`--default-open` の値を全モーラへ使う。

どの経路で決めたかは `--dry-run` と `--verbose` の診断に出る。

## 注意事項

- 出力する前に内容を確かめたいときは、オプション `--dry-run` を付けて実行する。対象トラック・
  採用した音符数・生成するキー数・開き量の統計が表示される。
- リップモーションの対象は歌唱トラック1つ。vpr に複数のトラックが入っているときはオプション
  `--track` で選ぶ(指定しなければ先頭のトラック)。
- 生成するのはあ・い・う・え・おの標準口モーフのみ。撥音は既定で閉口にし、`--n-morph` で「ん」
  モーフに切り替えられる。まばたき・眉などの表情モーフは生成しない。
- ピッチ・ビブラートなどの歌唱表現は再現しない。生成するのは口形と開き量のみ。
- 出力する VMD に入るのはモーフキーのみ。ボーン・カメラ・照明・セルフ影のセクションは空になる。
- 母音が得られない音符では直前の口形を継続する。既定の母音で口を開けて埋めることはしない。
- 発音区間が重なる音符があるときは警告を出し、重なりを解消してから変換する。
- 出力先パスに既存ファイルがある場合、`--overwrite` を付けない限り上書きしない。

## オプション

### 入出力

| オプション | 既定値 | 説明 |
|---|---|---|
| `<入力ファイル名>.vpr` | 必須 | 入力する vpr ファイル。 |
| `-o`, `--output PATH` | `<入力ファイル名>.vmd` | 出力先。指定しない場合は、入力ファイルの名前に `.vmd` を付けた VMD を作る。 |
| `--overwrite` | 無効 | 出力先に既にファイルがある場合の上書きを許可する。指定しない場合、出力先に既存ファイルがあると止まる。 |
| `--track NAME\|INDEX` | 先頭トラック | リップモーション対象の歌唱トラック。半角数字だけの指定は 0 から数えた番号、それ以外はトラック名として扱う。 |
| `--model-name NAME` | `vpr2vmd <バージョン>` | VMD に格納するモデル名(最大20バイト・Shift-JIS)。 |

### リップモーションの調整

| オプション | 既定値 | 説明 |
|---|---|---|
| `--style NAME` | `pop` | [歌い方スタイルプリセット](#歌い方スタイルプリセット)。開き量レンジ・タイミングをまとめて切り替える。 |
| `--open-max V` | プリセット値 | 口の開き量の上限(0.0〜1.0)。開けすぎを防ぐ。 |
| `--default-open V` | 開き量レンジの中央 | ベロシティが一様で強弱差が無いときに全モーラへ使う開き量(0.0〜1.0)。 |
| `--n-morph`, `--no-n-morph` | `--no-n-morph` | 撥音に「ん」モーフを使うかどうか。既定は閉口。「ん」モーフを持つモデルでは `--n-morph` を指定する。 |
| `--coartic-overlap FRAMES` | プリセット値 | 隣接母音の協調調音の重なり長の上限(フレーム)。 |
| `--anticipation FRAMES` | プリセット値 | 母音口形を音より先行させる最大フレーム数。`0` で無効。 |

### レガート間隙のつなぎ方

前後が母音(`--n-morph` 指定時は「ん」も含む)で間隙が短いときは、口を閉じきらず谷でつなぐ。間隙が
長いとき、または前後がそれ以外のときは閉口する。谷でつなぐ間隙長の境目と谷の深さを決める。

| オプション | 既定値 | 説明 |
|---|---|---|
| `--legato-max FRAMES` | `8.0` | 谷でつなぐ間隙長の上限(フレーム)。これを超える間隙は閉口にする。 |
| `--valley-shallow V` | プリセット値 | 谷の浅い側(0.0〜1.0)。大きいほど口を閉じずにつなぐ。 |
| `--valley-deep V` | プリセット値 | 谷の深い側(0.0〜1.0)。間隙が長いほどこの値へ近づく。 |
| `--valley-slope V` | プリセット値 | 間隙長1フレームあたりの谷の深まり方。 |

### テンポ補正

代表テンポが `--ref-bpm` より速い曲では、口形の保持・アタック・リリースのフレーム数を縮める。
基準より遅い曲では縮めない。

| オプション | 既定値 | 説明 |
|---|---|---|
| `--ref-bpm BPM` | `120` | テンポ補正の基準テンポ。 |
| `--tempo-scale-min S` | `0.5` | 縮める度合いの下限(0 超〜1.0)。小さいほど速い曲で強く縮める。 |

### 診断と出力確認

| オプション | 既定値 | 説明 |
|---|---|---|
| `--dry-run` | 無効 | 出力せず、対象トラック・採用した音符数・生成するキー数・開き量の統計などの処理計画と診断を表示する。 |
| `-v`, `--verbose` | 無効 | 出力 VMD は通常どおり書きつつ、`--dry-run` と同じ診断レポートを標準出力へ表示する。 |
| `--help` | — | オプションの一覧と短い説明を表示して終了する。 |
| `--version` | — | バージョンを表示して終了する。 |

### 機械利用(自動化・ツール連携)

他のソフトウェアから子プロセスとして呼び出して使うためのオプション。手作業で使うときは要らない。

| オプション | 既定値 | 説明 |
|---|---|---|
| `--machine` | 無効 | 画面(標準出力)への表示を1行1件の JSON(警告・結果・エラー)に切り替える。出力する VMD と終了コードは変わらない。 |
| `--describe` | 無効 | vpr を読まずに、受け付けるオプションとスタイルプリセットの一覧を JSON で出力して終了する。入力ファイルは要らない。 |

出力する JSON の形など、機械利用の詳しい仕様は [vpr2vmd.md](vpr2vmd.md) を参照。

さらに細かい仕様を確認したい場合は [vpr2vmd.md](vpr2vmd.md) を参照。
