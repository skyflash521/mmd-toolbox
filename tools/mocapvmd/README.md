# mocapvmd

モーションキャプチャー由来のボーンモーション VMD をノイズ軽減・足IK接地安定化してから
キーフレームを圧縮し、MMD で扱いやすい VMD を1コマンドで作るツール。
指定しなければ元の VMD はそのまま残して、最適化した新しい VMD を作る。

モーションキャプチャーのモーションは、細かい揺れ・足元の滑り・多すぎるキーフレームのせいで手直しし
づらいことが多い。mocapvmd は揺れと接地中の足の横滑りを抑え、動きの意図をできるだけ保ちながら
キーフレームを圧縮した VMD を出力する。

## 使い方

基本の形:

```sh
mocapvmd <入力ファイル名>.vmd [オプション]
```

例:

```sh
mocapvmd <入力ファイル名>.vmd -o <出力ファイル名>.vmd --preset medium
```

最適化した新しい VMD は、既定では入力した VMD と同じフォルダに `<入力ファイル名>_mocap.vmd` という名前で作られる(別の場所や名前にしたいときはオプション `-o` で出力先を指定する)。

全ボーンを処理対象にする。ボーンを選ぶオプションは無く、ボーン名から種類(センター・腕・指・足IK
など)を見分けて種類ごとに効かせ方を変える。カメラ・照明・モーフなどボーン以外のデータは、入って
いてもそのまま手を加えずに残す。

## プリセット

まとめて選ぶプリセットはキーフレームをどれだけ圧縮するかを選ぶ `--preset` の1つ。名前は処理の速さの
観点で、遅いほど元の動きに忠実でキーが多く、速いほどキーが少ない。

| 名前 | 特徴 |
|---|---|
| `slower` | 最も忠実(キー多め・処理遅め) |
| `slow` | やや忠実 |
| `medium` | 既定。編集しやすさと品質の両立 |
| `fast` | 圧縮・速度優先 |
| `faster` | 最大圧縮・最速 |

クリーニング(揺れの抑え方)の強さは、数値の倍率 `--clean-strength`(既定 `1.0`)で指定する。`0` で
クリーニングをほぼ無加工にし、上げるほど強く揺れを均す(`1.4` で全体を一様に強める)。強くしすぎると
指・手首などの細かい演技が丸まりやすいので注意する。

## 注意事項

- 出力する前に内容を確かめたいときは、オプション `--dry-run` を付けて実行する。ボーンの分類・
  キー数・足IK候補・どれくらいキーフレームを圧縮できるかが表示される。
- 既定では足の接地中の横滑りを除去する。意図的に足を滑らせるダンスなどでは、オプション
  `--foot-slide-suppression` を下げる(`0` で滑りをそのまま残す)。
- このツールは元の動きに手を加える(揺れを抑える・足の横滑りを補正する・キーフレームを圧縮する)。
  出力は元と完全に同じにはならない。とくに細部と接地中の足元の動きは変わる。
- ただし元の動きを大きく崩さないようにしている。大きなステップ・ジャンプ・ターン・手振りなどの
  動きのアクセントは保護し、全体のタイミングや重心移動の流れは保つようにしている。
- 入力は1フレームごとにキーが並んでいることを前提とする。キーがまばらな入力にキーを足す処理はしない。
- 次のことはしない: カメラ・照明・セルフ影の加工、物理シミュレーションや足裏接触の解剖学的補正、
  モーションキャプチャーの誤認識による大きなポーズ破綻の自動修復。
- 全身のボーンのキーフレームを圧縮するため、長い VMD では処理に時間がかかることがある。

## オプション

オプション `--preset` はキーフレームをどれだけ圧縮するか、オプション `--clean-strength` はクリーニングの
効き量を決める。どちらも指定しなければ既定値で動く。

### 入出力

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `<入力ファイル名>.vmd` | 必須 | 入力するボーンモーション VMD ファイル。 |
| `-o`, `--output PATH` | `<入力ファイル名>_mocap.vmd` | 出力先。指定しない場合は、入力ファイルの名前に `_mocap` を付けた VMD を作る。 |
| `--overwrite` | 無効 | 入力ファイルそのもの(同一パス)へ上書き出力することを許可する。指定しない場合、入力と同じファイルへ書こうとすると止まる。別名や別フォルダへの出力は指定不要。 |

### クリーニング(ノイズ軽減)

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `--clean-strength X` | `1.0` | ノイズ軽減の効き量の倍率。`0` でほぼ無加工、上げるほど強く均す。強くしすぎると細かい演技が丸まる。 |
| `--denoise`, `--no-denoise` | `--denoise` | ノイズ軽減のオン・オフ。`--no-denoise` でノイズ軽減をしない。 |
| `--denoise-mode MODE` | `bone` | ノイズ軽減の方式。`bone` はボーンごとに揺れを抑える。`pose` は MMD で実際に見える動き(ワールド軌跡)で評価して揺れを抑える。 |
| `--pmx PATH` | なし | `pose` 方式が参照するモデル PMX。指定しない場合は内蔵の標準的なモデル近似を使うため、PMX を用意しなくても動く。 |

### 足IK接地安定化

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `--foot-ik-stabilize`, `--no-foot-ik-stabilize` | `--foot-ik-stabilize` | 足IK・つま先IK の接地中のぐらつき抑制のオン・オフ。 |
| `--foot-slide-suppression S` | `1.0` | 接地中の横滑りを抑える強さ(0〜1)。既定の `1.0` は接地高さで滑っている足も接地とみなして横滑りを除去する。`0` で従来どおり滑りを保持する。意図的に足を滑らせる動きでは下げる。 |

### キーフレーム圧縮

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `--preset NAME` | `medium` | `slower` / `slow` / `medium` / `fast` / `faster` から選ぶ。キーフレームをどれだけ圧縮するかをまとめて指定する。緩めるほどキーが減って手で編集しやすくなり、そのぶん細かい動きが省かれる。 |
| `--reduce-error-bone-pos U` | プリセット値 | キーフレームを圧縮するときに許す位置のずれの基準値(MMD 距離単位)。明示するとプリセットより優先する。 |
| `--reduce-error-bone-rot DEG` | プリセット値 | キーフレームを圧縮するときに許す回転のずれの基準値(度)。明示するとプリセットより優先する。 |
| `--curve-mode MODE` | `bezier` | 出力する補間曲線。`bezier` はなめらかな曲線、`linear` は直線。 |
| `--no-reduce` | 無効 | キーフレームを圧縮せず、クリーニング後のキー(直線補間)をそのまま出力する。診断・比較用。 |

### 診断と出力確認

| オプション | 既定値 | 値と効き方 |
|---|---|---|
| `--dry-run` | 無効 | VMD を出力せず、ボーンの分類・キー数・範囲・足IK候補・どれくらいキーフレームを圧縮できるかなどの処理内容と診断を表示する。出力する前に結果を確かめる時に使う。 |
| `--list-bones` | 無効 | ボーンの一覧と、見分けた種類(分類)を表示して終了する。 |
| `--quiet` | 無効 | 進捗表示を抑制する。出力 VMD や診断の内容は変わらない。 |
| `--version` | — | バージョンを表示して終了する。 |

さらに細かい仕様を確認したい場合は [mocapvmd.md](mocapvmd.md) を参照。
