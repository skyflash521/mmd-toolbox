# 変更履歴

## 0.0.3 - 2026-11-14

### 破壊的変更

- `--denoise-mode pose` で `--clean-strength` に 1.0 以外を指定すると引数エラー(終了コード2)にした。これまでは受け付けるが効かなかった。
- `--pmx` が存在しない・通常ファイルでない場合、方式や `--no-denoise` に依らず入力不正(終了コード1・`pmx_not_file`)にした。
- ボーンキーの無い VMD を入力不正(終了コード1・`no_bone_keys`)にした。これまではそのまま書き出していた。

### 追加

- キーがまばらな入力に対応した。1フレーム刻みに補間してから処理する。`--no-reduce` では毎フレームのキーを出力する。
- `--dry-run`・`--verbose` のレポートに、種別ごとの集計(動きの変化量の最大・平均、保護フレーム数、足IKのロック適用率)を加えた。
- キーフレーム圧縮中の進捗に、ボーン内のフレームの進み具合を出すようにした。
- 機械利用: キーフレーム圧縮中も `progress` を一定間隔で送るようにした。
- 機械利用: `--describe` の各オプションに `repeat` を加えた。

### 変更

- 末尾に余分なデータがある VMD を、警告(`trailing-bytes`)を出して処理するようにした。余分なデータは出力の末尾に残す。
- `--help` と `--describe` で、`--dry-run`・`--verbose`・`--quiet` を `--overwrite` の直後へ移した。
- `--clean-strength`・`--foot-slide-suppression`・`--reduce-error-bone-pos`・`--reduce-error-bone-rot` の値が誤っているときのエラー文言を `argument <オプション>: <理由>: '<値>'` にそろえた。エラーコードと終了コードは変わらない。
- `pose` 方式と `--no-denoise` のレポートに、bone 方式のノイズ軽減の項目を出さないようにした。

### 修正

- 同じボーン・同じフレームのキーが重複しているとき、後に現れたキーを採用し、警告(`normalize-duplicate`)を出すようにした。
- `pose` 方式のレポートで、足IK接地の診断が bone 方式を前提にした値になっていたのを直した。
- PMX の不正で止まるとき、エラーが進捗の行に続けて出ていたのを直した。
- 親の番号が範囲外、または循環している PMX で `internal_error` が出ていたのを、`not_pmx` にした。

## 0.0.2 - 2026-08-08

### 破壊的変更

- `--overwrite` が守る範囲を広げた。これまでは出力先が入力と同じパスのときだけ上書きを止めていたが、出力先に別の既存ファイルがある場合も止めるようになった。既存ファイルへ書くには `--overwrite` を付ける。
- 機械利用: 上書きガードのエラーコードを `output_overwrites_input` から `output_exists` へ変えた。

### 追加

- 出力先にディレクトリを指定した場合、`--overwrite` の有無に依らず専用のエラー(`output_is_directory`)で止まるようにした。
- Windows で `CTRL_BREAK_EVENT` による中断を、Ctrl-C と同じ中断として扱うようにした。

### 変更

- 入力ファイルが無い場合と `--pmx` のファイルが無い場合の終了コードを、引数エラー(2)から入力不正(1)へ変えた。
- 警告の表示にコードを含めるようにした(`警告: <本文>` から `warning: <コード>: <本文>` へ)。
- オプションの指定を誤ったときの画面表示を1行にまとめた。

### 修正

- 進捗表示の書き込みに失敗しても処理が止まらないようにした。
- 機械利用で標準出力へ書き込めない場合に、失敗の理由を画面(標準エラー)へ出すようにした。
