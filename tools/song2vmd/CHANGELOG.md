# 変更履歴

## 0.0.2 - 2026-11-14

### 追加

- 機械利用: `--describe` の各オプションに `repeat` を加えた。

### 変更

- 長い曲では、全区間のボーカル分離を済ませてから音素認識をまとめて行い、モデルの読み込みを1回にした。音素認識の進捗の総数は区間数の2倍になる。
- 英単語の発音辞書(CMUdict)が無いとき、曲に依らず音素認識の前に取得するようにした(進捗表示「辞書取得中」)。取得できなければ終了コード4で止まる。
- ボーカル分離のモデルの保存先を `~/.cache/audio-separator-models/` に固定した(Windows は `%USERPROFILE%\.cache\audio-separator-models\`)。更新後の初回は取得し直す。以前の `/tmp/audio-separator-models/` は削除してよい。
- `--keep-intermediate` で残す `vocal.wav` を、分割しない曲でも音量をそろえず保存するようにした。VMD は変わらない。
- `--keep-intermediate` で残す `segments.json` から、常に `null` だった `confidence` を除いた。
- `--help` と `--describe` で、出力・実行制御のオプションを後ろへまとめた。
- `--coarticulation` の説明を「隣接母音のあいだで口形を移す長さ」に改めた。

### 修正

- `--help` と `--describe` のオプションの説明に、工程の内部番号やモジュール名など内部の用語が出ていたのを直した。
- 「デュ」「テュ」「フュ」「クヮ」「グヮ」を含む曲で、音素認識が失敗して止まっていたのを直した。
- 口形の移り変わりが指定の長さを超えて延びていたのを直した。
- 単語の時間が音素の数に比べて短すぎる箇所で、口の動きがずれていたのを直した。
