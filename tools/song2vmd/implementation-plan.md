# song2vmd 実装計画書

> **このドキュメントは実装完了後に削除される一時的な計画書である。** 仕様書・コード・コミットメッセージからこのドキュメントを参照してはならない。

要求仕様 [song2vmd.md](song2vmd.md) を実装へ落とす計画。TDDで見出し単位のステップを進める。本書は仕様を
変更せず、仕様が実装での確定に委ねた詳細を定め、着手順序とテスト方針を決める。仕様と矛盾が生じた場合は
仕様(song2vmd.md)を正とし、本書を直す。

---

## 1. 前提と依存

- 実装言語 Python 3.11+。本リポジトリ本体の必須依存は `numpy`/`scipy` のまま保つ。
- 音声前段(S0–S3: 入力読み込み・ボーカル分離・音素認識・RMS算出)と S-1認識ゲート、およびその重い依存
  (分離・認識のライブラリ・モデル)は共有モジュール [vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) に
  委譲する(採用ツール・受入基準は [vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) §8・§9)。
  重い依存は vocal_analysis 側に閉じる。
- VMD 書き出しは `vmd.io`。生成するのはモーフキーのみ(汎用疎化は使わない。song2vmd.md §9)。
- アニメ的口パクのキーフレーム生成は共有モジュール [lipsync](../../libs/lipsync/lipsync.md) に委譲する。`song2vmd` は
  口形イベント列と開き量を作って `lipsync` へ渡す(モーフ生成コア・既定プロファイルは
  [lipsync 仕様](../../libs/lipsync/lipsync.md))。
- 音声前段の外部ツールは vocal_analysis が内部で呼ぶ。利用者は `song2vmd INPUT` の1コマンドのみ。

## 2. 実装ステップ(着手順)

各ステップは「テスト作成 → レビュー → 収束ならコミット」「実装 → レビュー → 収束ならコミット」を回す
(自律開発の単位)。外部ツールに依存するステップは、ユニットテストではモックまたは短い小サンプルを使い、
ネットワーク・GPU・実モデルを必須にしない。

**ツール横断の着手順**: アニメ的口パクのモーフ生成コアは共有モジュール `lipsync` にあり、`vpr2vmd`(vpr
入力・認識不要)で先に実装・チューニングして見た目の品質を詰める。音声前段(S0–S3)と S2母音認識の成立可否
(S-1ゲート)は共有モジュール `vocal_analysis` の実装で行い
([vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) §2 の S0–S3 と §9 のゲート)、S-1ゲートは `vpr2vmd` と
並行に早期評価する。`song2vmd` は、実証済みの `lipsync` コアと `vocal_analysis` の共有出力へ、入口処理
(口形イベント確定・RMS→開き量)を接続する位置づけで、S-1ゲート合格後に進める。下表のうち S-1〜S-5 は
`vocal_analysis` 側の実装で、S-0・S-6〜S-11 が `song2vmd` 固有のステップ。

| 区分 | ステップ | 内容 | 主な受入条件 |
|---|---|---|---|
| 基盤 | S-0 | パッケージ雛形・CLI骨組み(引数パース)・依存宣言・`--dry-run` の空実行 | CLIが起動し引数を解釈する |
| 前段(vocal_analysis) | S-1〜S-5 | S-1 認識ゲート・S0 入力読み込み・S1 ボーカル抽出・S2 音素認識・S3 強弱RMS算出は `vocal_analysis` が担う([vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) §2 の S0–S3、受入基準・認識器固定・推論条件は同 §9・§5.1) | vocal_analysis の受入条件に従う。S-1ゲート合格後に song2vmd の入口(S-6)へ進む |
| 中核 | S-6 | 口形イベント確定(入口): vocal_analysis の音素セグメント列＋RMSから、IPA→5母音写像の適用・両唇閉鎖判定・gap解決・無音/閉口確定・母音境界のオンセット補正で口形イベント列を確定。各モーラのRMSから開き量を決定(4.2・4.3・4.6) | 口形イベント列(母音・両唇閉鎖・無音)と開き量が決定論的に得られる |
| 中核 | S-7 | S4 モーフ生成: 口形イベント列＋開き量＋プリセットを共有モジュール `lipsync` へ渡しモーフキーを生成([lipsync.md](../../libs/lipsync/lipsync.md) §4)。VMD出力は `vmd.io` | lipsync.md §3 の品質基準を満たす疎なモーフキーVMDを出力 |
| 段 | S-8 | 長尺分割(無音区切り/無音なし時は最大チャンク長で強制分割、オーバーラップ・中央採用・継ぎ目結合・曲全体RMS正規化) | 継ぎ目でキーの重複・欠落がなく、境界母音が結合され(再アタック・保持値跳ねなし)、中央採用・曲全体RMS基準が保たれる |
| 仕上げ | S-9 | スタイルプリセット(8.1)とパラメータ確定 | プリセットで開き量レンジ・タイミングが切り替わる |
| 仕上げ | S-10 | レポート/診断(`--dry-run`)・`--keep-intermediate` | 仕様6.7の統計を出力 |
| 仕上げ | S-11 | 統合・E2E(小サンプルで音声→VMD)。**公開時に README のツール表へ `song2vmd` を追記**(README 本体は指示があるまで触らない) | 1コマンドで口パクVMDを生成。**同一音源のゲイン違い入力(分離あり通し)で同一セグメント・同一VMD**(入力ゲイン不変性。6.1) |

依存関係: S-1〜S-5(vocal_analysis)のうち S-1ゲートは `vpr2vmd` と並行に早期確定し、合格後に song2vmd の
入口(S-6)へ進む。S-6 は vocal_analysis の出力(音素セグメント列・RMS)に依存し、S-7 は S-6 の口形イベント列・
開き量を `lipsync` へ渡す。S-8 はチャンク単位で vocal_analysis(S0〜S2)まで処理し、結合後に S-6 の入口処理と
S-7 の `lipsync` 生成を全曲へ1回適用する(4.5)。

## 3. テスト方針

- `vmd` のテスト規約(pytest・決定論・乱数シード固定・ネットワーク/GPU 不要)に従う。
- 入出力のVMDはラウンドトリップと既知値フィクスチャで検証。モーフキーの値・フレーム・名称(Shift-JIS)を確認。
- 音声前段(S0–S3)の外部モデル依存は vocal_analysis 側に隔離される([vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) §8 のアダプタ)。`song2vmd` の
  入口処理(S-6 の gap解決・あいうえお写像の適用・閉鎖判定、および S-8 の継ぎ目結合の中核)は正規化中間形式
  (セグメント列・RMS)だけに依存させ、合成したセグメント列＋合成RMSのフィクスチャで決定論的にモックテストする。
- **共有モーフ生成コア(`lipsync`)の正しさ・回帰は、`song2vmd` と `vpr2vmd` のツール間比較では捉えられない**
  (両者は同じ `lipsync` コアを通るため相殺される)。lipsync コアの回帰は
  [lipsync 仕様](../../libs/lipsync/lipsync.md) §7 の既知値フィクスチャで担保する(ツール間比較で
  代替しない)。`song2vmd` 側は S-7 で口形イベント列・開き量を `lipsync` へ渡す接続を検証する。
- S-8 のチャンク制御は vocal_analysis(S0–S2)を扱うため、純関数の核(継ぎ目結合・無音判定ヒステリシス)を
  分離してテストし、前段呼び出し部は小サンプルまたはモックで確認する。RMS算出(S3)自体の純関数核テストは
  vocal_analysis 側で行う。
- 実モデルを使う検証(S-1ゲート)は vocal_analysis 側で重テストとして分離し、通常の `pytest` には含めない
  ([vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) §9)。
- **開発時のE2E検証(vpr由来データ)**: 音声と対の vpr があるとき、`song2vmd`(音声)の出力する口形イベント列を、
  同じ vpr 由来の口形イベント(同じ vpr を入れた `vpr2vmd` の出力)と突き合わせ、認識・入口側の誤差の傾向を見る。
  **未監査の vpr は厳密な正解でなく補助比較に限る**(正式な合否は §4.1 の監査済みゲートデータで行う)。これは
  pytest 外の開発時確認で、共有コア(`lipsync`)の回帰検出には使えない(両者は同じコアを通るため。回帰は上記の
  既知値フィクスチャで担保)。

## 4. 確定する詳細(初期値・手順)

仕様が実装での確定に委ねた項目を、初期値と手順としてここで確定する。値は出発点で、代表サンプルで
チューニングする(ただし §4.1 の S-1 ゲートの評価集合・閾値・集計規則は除く。下記のとおり採点前に固定する)。**時間単位**: 音声解析(4.1〜4.3)は秒/ms で扱う。出力キー生成(4.4)は30fps基準
(1秒=30フレーム)で、最終的にVMDキーを30fps整数フレームへ量子化する。

### 4.1 S2受入基準(S-1ゲート)

S-1認識ゲート(代表データ・ラベル・vpr由来自動ラベルと監査・採点対象段階・母音正解率・過開口率・区間
対応付け・境界ずれ・集計受入基準・再現性)は共有モジュール `vocal_analysis` の責務であり、
[vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) §9 を正本とする。`song2vmd` は S-1ゲート
合格後に入口(S-6)へ進む。本書では重複定義しない。

### 4.2 母音境界の確定とgap解決(入口)

認識器の固定(モデルid/revision・16kHz mono・推論条件)、CTC区間化(60ms吸収)、IPA→5母音写像規則は
`vocal_analysis`([vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) §5.1・§7)が正本。
`song2vmd` 入口は vocal_analysis の母音/子音/gap セグメント列＋IPAラベルへ次を適用して口形イベント列を確定する
(処理順は4.6)。

- **IPA→5母音写像の適用**: vocal_analysis の写像規則(vocal_analysis.md §7)を母音セグメントへ適用する。
- **両唇閉鎖判定(入口)**: 子音セグメントのうち両唇音(m/b/p/ɸ/β)を閉鎖として扱う(音素由来、RMS非依存)。
- **母音境界の精緻化**: 母音区間の開始を、前後 ±60ms 以内に RMS オンセット(立ち上がり)があればそれへ
  寄せる。無ければトークン境界を採用。
- **RMSオンセット検出**: 正規化RMSを ~30ms 移動平均で平滑化し、探索窓内で上昇の傾きがしきい値(初期
  +0.15/10ms)を超える最初の点をオンセットとする。複数候補があれば母音区間の元境界に時間的に最も近いものを選ぶ。
- **gap解決(入口)**: gap 区間の代表RMSが無音しきい値(4.3)以下なら無音(閉口)、以上なら直前母音を継続。
  ただし直前母音が無い先頭gap、および末尾gapは(RMSによらず)閉口とする(先頭・末尾は閉口で始終する。4.6)。

### 4.3 強弱(RMS)消費・閉口(初期値)

- **RMS算出**: RMSエンベロープの算出(フレーム長・ホップ)と曲全体パーセンタイル相対正規化は vocal_analysis
  (vocal_analysis.md §6.1。長尺分割時も曲全体基準。4.5)。`song2vmd` 入口はその相対正規化RMSを消費する。
  母音中央代表は区間中央 60% の平均(母音区間は vocal_analysis の音素セグメントから)。
- **無音ヒステリシス**(正規化RMS): 開いている状態からは RMS が下降側しきい値 0.06 を下回ったら閉口へ入り、
  閉じている状態からは上昇側しきい値 0.10 を上回ったら開口へ戻る(下降側 < 上昇側。初期値)。
- **低ダイナミクス抑制**(song2vmd.md 6.4): 曲のダイナミックレンジ(例: 95〜5パーセンタイルRMSのdB差。比なので
  ゲイン不変)が下限(初期 12dB、実データで補正)未満なら、その曲は実質無音が無いとみなし、音量に基づく無音化
  (gap無音化・母音無音補正)を抑制する(音素由来の両唇閉鎖・先頭/末尾の閉口は対象外)。終始大音量の曲の閉口
  誤検出を防ぐ。絶対dBFSしきい値は使わない(入力ゲインに不変)。
- **母音区間の無音補正**: 母音セグメントでも代表RMSが無音(下降側しきい値 0.06)以下なら、信頼度によらず閉口に
  する(高信頼でも実RMSが無音の誤検出母音対策。仕様)。
- **両唇閉鎖**: 深さ=全母音0、長さ=子音区間長(上限 100ms)。

### 4.4 生成パラメータ(プリセット値)・開き量の決定

モーフ生成のアルゴリズム(母音合成・協調調音の遷移長・最小保持の併合/間引き・区間内競合短縮・連結区間内の
強弱節点・30fps量子化・伸び揺らぎ)と**既定の母音合成プロファイル**は共有モジュール `lipsync` が持つ
([lipsync 仕様](../../libs/lipsync/lipsync.md) §4 が正本)。本節は `song2vmd` が `lipsync` へ渡す
**プリセットの具体値**と、`song2vmd` 入口の **RMS→開き量の写像・低信頼判定**を定める。時間はフレーム(30fps)。
`pop` を基準とし、他プリセットは開き量レンジと下表を調整する(値は `lipsync` のタイミング/誇張パラメータへ渡す)。

| 項目 | pop | ballad | powerful | whisper | rap |
|---|--:|--:|--:|--:|--:|
| 開き量レンジ(弱〜強) | 0.30–0.75 | 0.20–0.55 | 0.40–0.95 | 0.10–0.35 | 0.30–0.70 |
| アタック | 2 | 3 | 1 | 2 | 1 |
| リリース | 2 | 3 | 1 | 2 | 1 |
| 協調調音 重なり(上限) | 2 | 3 | 2 | 2 | 1 |
| 先行(anticipation) | 1 | 1 | 2 | 1 | 1 |
| 最小保持 | 3 | 4 | 3 | 3 | 2 |
| 合成誇張係数 | 1.0 | 0.8 | 1.3 | 0.7 | 1.0 |

- **強弱→開き量(入口。RMS→開き量の写像)**: 区間代表RMSを 0〜1 に正規化し、累乗指数 0.6(初期)で写像、
  開き量レンジへクランプ、`--open-max` で上限。`--open-max` 既定はプリセット値(pop 0.90 / ballad 0.70 /
  powerful 0.97 / whisper 0.50 / rap 0.85。各プリセットの開き量レンジ上限以上)。こうして決めたモーラ別開き量を
  `lipsync` へ渡す(合成プロファイルへの適用・合成総量の上限クランプは `lipsync` 側。lipsync 仕様 §4.1)。
- **`--vowel-gain`**: 既定 1:1:1:1:1(a:i:u:e:o)。母音別の開き量倍率として `lipsync` へ渡す(適用順は
  lipsync 仕様 §4.1)。
- **合成誇張係数**: 上表の値を `lipsync` の母音合成プロファイルの補助重みへ掛ける誇張係数として渡す(適用は
  `lipsync` 側)。
- **低信頼・無声母音(入口判定)**: 認識器が信頼度を出す場合、信頼度 < 0.5 かつ 正規化RMS < 0.3 の母音区間を
  「弱い」と判定し、開き量を 0.5 倍に弱めて `lipsync` へ渡す(区間長が最小保持未満なら `lipsync` の最小保持で
  前後へ吸収される)。信頼度を出さないバックエンドでは正規化RMS のみで判定する(< 0.2 を弱いとみなす)。

### 4.5 長尺分割(初期値)

- 最大チャンク長 = `--max-duration`(既定300秒)。チャンク境界は、目標境界の前後 ±5秒で最も静かな点(無音)を
  探す。無音が無ければ目標境界で強制分割。隣接チャンクは前後 1.0秒 オーバーラップさせる。
- 継ぎ目は**セグメント段階で結合してからキー生成する**(キー生成はチャンク単位でなく結合後の全体で1回行う):
  1. 各チャンクを vocal_analysis(S0〜S2)まで個別処理し、母音/子音/gap のセグメント列を得る。
  2. オーバーラップ区間は、チャンク中央に近い側のセグメントを採用して重複を除く(中央区間採用)。
  3. チャンク境界をまたぐ同一母音セグメントは1区間へ結合する(再アタック・閉口を挟まない)。
  4. 結合した全曲セグメント列に中核の処理順序(4.6)を適用し、`lipsync` でキー生成を1回行う。
- RMS の相対正規化(4.3)は曲全体を基準にし、チャンクごとに基準がずれないようにする。

### 4.6 中核の処理順序(決定論)

`vocal_analysis` は CTC区間化済みの 母音/子音/gap の全被覆セグメント列(IPAラベル付き)と相対正規化RMSを共有
出力として渡す(vocal_analysis.md §5.1・§7)。`song2vmd` 入口はそのセグメント列に次の順で適用し、結果を
一意にする(S3のRMSを併用):

1. IPA→あいうえお写像・両唇音→閉鎖判定(4.2)。
2. gap解決: RMS で gap を無音(閉口)/直前母音継続に確定。母音区間の無音補正も行う(4.3)。ただし低ダイナミクス
   曲(4.3)では、この音量に基づく無音化・無音補正を抑制する(音素由来の両唇閉鎖・先頭/末尾の閉口は対象外)。
3. 同母音連結: 連続する同一(あいうえお)母音区間を1つの口形イベントへまとめる。
4. 母音境界の RMS オンセット補正(4.2)。境界はここで確定する。
5. 低信頼・無声判定: 弱い母音を抽出し開き量を弱める(4.4)。
6. ここまでで確定した口形イベント列(母音・両唇閉鎖・無音)とモーラ別開き量・プリセットを `lipsync` へ渡す。
   最小保持未満の併合/間引き、キー配置(アタック・保持・遷移・閉口・先行)、30fps整数フレームへの量子化
   (同一モーフ・同一フレームのキー衝突解決を含む)は `lipsync` が行う(lipsync 仕様 §4)。

- 先頭は閉口から始め、末尾は閉口で終える。判定が同値(RMS等)で割れる場合は連結(直前優先)側に倒す。

## 5. リスクと未確定

- **S2品質(最大リスク)**: 歌唱での母音認識が受入基準に届くか。これは vocal_analysis の S-1ゲートで先に潰す
  (届かなければ vocal_analysis 側で認識器を差し替える)。音声前段の依存の重さ・速度・決定論(分離・認識の
  モデル取得・非決定性)も含め、これらは vocal_analysis 側のリスク([vocal_analysis](../../libs/vocal_analysis/vocal_analysis.md) §8)。
- **song2vmd 固有の未確定**: 入口処理(口形イベント確定・RMS消費による開き量決定)の各初期値(4.2〜4.4)、長尺の
  継ぎ目結合(4.5)、`lipsync` への接続。これらは vocal_analysis の共有出力が揃った後に詰める。

## 6. 仕様への影響

本計画の作成で判明した、要求仕様(song2vmd.md)の変更要否:

- 仕様の記述変更が必要な不整合は無い(責務・パイプライン・中間形式・ライセンスは確定済み)。本計画は仕様が
  実装での確定に委ねた詳細(4章)の置き場であり、仕様の決定を覆さない。
- 実装着手後、4章の数値確定や S-1 ゲートの結果で仕様の前提が崩れた場合(例: 認識器の差し替え)は、
  正本である song2vmd.md を先に更新してから本計画と実装を整合させる。
