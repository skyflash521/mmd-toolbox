# 変更履歴

## 0.0.3 - 2026-08-08

### 破壊的変更

- `--overwrite` が守る範囲を広げた。これまでは出力先が入力と同じパスのときだけ上書きを止めていたが、出力先に別の既存ファイルがある場合も止めるようになった。既存ファイルへ書くには `--overwrite` を付ける。
- 機械利用: 上書きガードのエラーコードを `output_overwrites_input` から `output_exists` へ変えた。

### 追加

- 出力先にディレクトリを指定した場合、`--overwrite` の有無に依らず専用のエラー(`output_is_directory`)で止まるようにした。
- Windows で `CTRL_BREAK_EVENT` による中断を、Ctrl-C と同じ中断として扱うようにした。
- 進捗表示のベイクの段に、処理済みフレーム数と総数を出すようにした。

### 変更

- オプションの指定を誤ったときの画面表示を1行にまとめた。
- 警告とエラーの本文から、内部の仕様書の節番号を取り除いた。

### 修正

- 機械利用で標準出力へ書き込めない場合に、失敗の理由を画面(標準エラー)へ出すようにした。

## 0.0.2 - 2026-07-03

### 破壊的変更

- `--preview-csv` オプションを削除した。フレームごとの揺れ量の CSV 出力は無くなり、実行前の確認は `--dry-run` の表示に統合された。

### 追加

- 進捗表示: 処理の経過(段の名前と経過時間)をターミナルへ1行で表示し、出力を書き終えると「完了 <出力先>」を残す。`--quiet` で表示を消せる。
- `--version`: バージョンを表示して終了する。
- 機械利用(自動化・ツール連携)向けオプション: `--machine` は進捗・警告・結果・エラーを1行1件の JSON で出力する。`--describe` は受け付けるオプションとプリセットの一覧を JSON で出力して終了する。`--machine` では `--dry-run` が入力検査の結果を JSON で返し、Ctrl+C による中断も中断として報告する。

### 修正

- 進捗・警告の表示が、端末の文字コードによってはエラーになることがあった問題を修正。
