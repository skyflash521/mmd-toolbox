# sparsevmd 仕様書

層: **CLIツール層**([../../docs/conventions/layering.md §1](../../docs/conventions/layering.md#1-層タクソノミー))。

連続フレームにキーがある高密度のカメラ・ボーンモーションを、MMD で扱いやすい数の疎なキーと補間曲線へ
変換する。変換後の再生は指定した許容誤差以内に収め、補間曲線で編集できる形に戻す。

## 要求

- 既定設定で、対話的に待てない時間まで処理が終わらない状態は性能回帰とする。

## 対象範囲

- 削減するのはカメラキーとボーンキーだけで、モーフ・照明・セルフ影・IK のキーはそのまま出力する。
- 削減の対象にしたセクションは、入力とのバイト一致とキーの並び順を保たない。
- 元のモーションを近似するだけで、ノイズ除去・足の接地補正・IK 補正・姿勢推定の修正は行わない。
- VMD に無い補間方式、30fps 以外へのリサンプリング、GUI は持たない。

## 互換性

- `sparsevmd.fit`・`sparsevmd.reduce`・`sparsevmd.cuts` の import パスは維持する。
