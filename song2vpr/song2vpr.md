# song2vpr 要求仕様書

歌の音声ファイルから VOCALOID プロジェクトファイル(vpr)を生成する独立CLIツールの要求仕様。

---

## 1. 位置づけ

### 1.1 結論

本機能は `song2vpr` という独立CLIツールとして提供する。

`song2vpr` は、日本語の歌の音声ファイル(BGM込み可)を入力に、ボーカル抽出・音素認識(共有モジュール
`vocal_analysis`)＋ F0ピッチ推定 ＋ 音符分割・歌詞/音素対応付けを経て、共有モジュール `vpr_io` で vpr を
**1コマンド**で書き出す。

```text
入力 音声ファイル(歌, mp3/wav 等)
  -> song2vpr(vocal_analysis: 分離・音素認識 → F0ピッチ推定 → 音符分割・歌詞/音素対応付け → vpr_io 書き出し)
  -> vpr
  -> VOCALOID で確認・編集
```

### 1.2 設計境界

CLAUDE.md の設計境界に従う。

- **音声前段**(ボーカル抽出・音素認識・ボーカルWAV・RMS)は共有モジュール
  [vocal_analysis](../vocal_analysis/vocal_analysis.md) に委譲する。
- **vpr の書き出し**は共有の形式I/Oモジュール [vpr_io](../vpr_io/vpr_io.md) に委譲する。`song2vpr` は vpr の
  バイナリ/直列化構造を直接扱わない。
- **`song2vpr` 固有**: F0ピッチ推定(ボーカルWAV→F0→音高)、音符分割、歌詞/音素対応付け、CLI引数。

### 1.3 独立ツールとする理由

- 出力が vpr(音符＝**ピッチ**を持つ)で、口パクVMD(`song2vmd`)とは必要情報が異なる。`vpr` はピッチを持ち
  強弱は音符のベロシティ/ダイナミクスで表す。共有するのは音声前段(`vocal_analysis`)で、ピッチ推定・音符化は
  `song2vpr` 固有。
- 主たる新規リスクは**ピッチ系**(F0推定・音符分割)で、音素認識は `vocal_analysis` で実証済みのものを使う。
- `song2vpr` は口形イベントを要さないため、`vocal_analysis` の共有出力は音素粒度で足りる(口形イベント確定は
  `song2vmd` 入口の話で、`song2vpr` は使わない)。

---

## 2. 目的

### 2.1 解きたい問題

歌の音声から VOCALOID で編集できる vpr(ピッチ・歌詞・音符のあるプロジェクト)を起こすのは手間が大きい。
音声から音符(ピッチ・時刻・歌詞/音素・強弱)を自動抽出し、vpr の下書きを生成して編集の出発点にする。

### 2.2 非目標

- 口パクVMD は生成しない(それは `song2vmd`)。
- 完全な歌唱合成・採譜の完全自動化は対象外。あくまで編集の出発点となる vpr 下書きを作る。
- 日本語以外は対象外(音素認識・歌詞対応が日本語前提)。

---

## 3. 処理パイプライン

```text
入力 音声ファイル(歌, BGM込み可)
  ├─ 音声前段          vocal_analysis(共有)→ ボーカルWAV・音素セグメント列(母音/子音/gap＋IPA)
  ├─ F0ピッチ推定      song2vpr側 → ボーカルWAVから時刻ごとの基本周波数(F0)・有声/無声
  ├─ 音符分割・対応付け song2vpr側 → F0＋音素セグメントから音符(ピッチ・開始/長さ・歌詞/音素・強弱)
  └─ vpr 書き出し      vpr_io(共有)→ vpr
```

- **音声前段(vocal_analysis)**: ボーカル抽出・音素認識は `vocal_analysis` に委譲し、ボーカルWAVと音素セグメント
  列を得る(vocal_analysis.md §2〜§6)。
- **F0ピッチ推定(`song2vpr` 固有)**: `vocal_analysis` のボーカルWAVから F0(基本周波数)と有声/無声を推定し、
  音高(半音/ノート番号)へ写像する。ピッチ推定は `song2vmd` では不要なため `vocal_analysis` には含めず、
  `song2vpr` 固有処理として置く。
- **音符分割・歌詞/音素対応付け(`song2vpr` 固有)**: F0 の安定区間と音素セグメントの境界から音符を切り、各音符に
  音高・開始時刻・長さ・歌詞/音素・強弱(ベロシティ/ダイナミクス相当)を割り当てる。歌詞/音素の対応付けは音素
  セグメントを基にする(意味のある歌詞書き起こしは行わない。必要なら任意指定の歌詞テキストで精度を上げる余地を
  残す)。
- **vpr 書き出し(vpr_io)**: 音符列・テンポを `vpr_io` のデータモデルへ載せ、vpr を書き出す(vpr_io.md §2・§4)。
  `vpr_io` の書き出しは `song2vpr` 着手時に拡張する(vpr_io 実装計画 V-3)。

## 4. コマンドライン仕様

### 4.1 書式

```text
song2vpr INPUT [options]
```

`INPUT` は音声ファイル。既定出力は `<入力名>.vpr`。

### 4.2 主なオプション(初期案)

| 引数 | 既定 | 説明 |
|---|---:|---|
| `INPUT` | 必須 | 入力音声ファイル |
| `-o, --output PATH` | `<入力名>.vpr` | 出力 vpr |
| `--overwrite` | off | 既存出力の上書きを許可 |
| `--separate-vocals MODE` | `auto` | ボーカル分離 `auto` / `always` / `never`(vocal_analysis へ渡す) |
| `--recognizer NAME` | 採用ツール固定 | 音素認識バックエンド選択(vocal_analysis へ渡す)。初期は固定 |
| `--tempo BPM` | 自動/指定 | テンポ。指定が無ければ推定(推定可否は実装で確定) |
| `--lyrics PATH` | なし | 任意の歌詞テキスト(与えると歌詞/音素対応の精度向上に使う) |
| `--report-json PATH` | なし | 音符数・ピッチ・音素被覆などの処理統計を出力 |
| `--dry-run` | off | 出力せず処理計画と診断を表示 |

音声前段のバックエンド選択(`--separate-vocals` / `--recognizer`)は `vocal_analysis` のアダプタを CLI で公開する
(選択肢の追加・切り替えは vocal_analysis 側。vocal_analysis.md §8)。

---

## 5. 入出力要件

- 出力 vpr の書き出しは `vpr_io` に委譲する。`song2vpr` は vpr のバイナリ/直列化構造を直接扱わない。
- 音声前段(分離・認識)は `vocal_analysis` の共有出力を使う。利用者は `song2vpr INPUT` の1コマンドだけを実行し、
  外部ツールは内部で呼ばれる。
- 出力の再現性: 外部ツール(分離・認識・F0推定)が非決定的な場合があるため、可能な範囲で決定論を目指す
  (完全な決定論は外部ツール依存であることを明記する)。

---

## 6. vocal_analysis・vpr_io との関係

- 音声前段(分離・認識・ボーカルWAV)は `vocal_analysis`、vpr 書き出しは `vpr_io`。`song2vpr` は両者を束ね、
  ピッチ推定・音符分割・歌詞/音素対応付けという `song2vpr` 固有処理を担う。
- 時間軸: `vocal_analysis` の出力は秒。`vpr_io` は vpr のテンポ・拍子に基づく時間表現(tick/拍)を扱う。秒⇔
  tick/拍 の変換(テンポの推定/指定を含む)は `song2vpr` 側で行う。
- 設計境界どおり、CLI は別CLIに依存しない(`song2vmd.md` を参照しない)。共有は `vocal_analysis`・`vpr_io` を
  通じてのみ行う。
