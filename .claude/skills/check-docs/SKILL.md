# 仕様書整合チェック(Haiku委譲)

走査はHaikuサブエージェントに委譲し、メインモデルは候補の文脈精査と報告のみ行う。
**このスキルは修正をしない**。報告した候補を修正するかはユーザーの判断。

## 対象ファイル

- README.md
- CLAUDE.md
- mmd_toolbox/mmd_toolbox.md
- mmd_toolbox/vmd-io.md
- mmd_toolbox/vmd-interp.md
- mmd_toolbox/vmd-camera.md
- mmd_toolbox/tests/data/README.md
- shakevmd/shakevmd.md
- docs/specs/vmd/VMD_file_format.md

## チェック項目

1. **節参照**: 「§x.y」「テストn」が参照先のファイルに実在するか
   (同一ファイル内参照と「vmd-io.md §5」のようなファイル指定参照の両方)
2. **ファイル相互参照**: パス参照・Markdownリンクの参照先ファイルが実在するか
3. **用語規約**(候補として列挙する。例外規則があるため機械的に違反と断定しない):

| 禁止・注意表記 | 正 | 例外 |
|---|---|---|
| 補間カーブ、裸の「カーブ」 | 補間曲線 | なし |
| FOV | 視野角 | コード識別子 `fov` |
| 注視点、ターゲット | カメラ中心 | なし |
| モーフセクションの呼称としての「表情」 | モーフ | 表情モーフ(モーフの種類名)は可 |
| セルフシャドウ | セルフ影 | 英語見出し Self Shadow は可 |
| パースペクティブ(UI操作・データ作成手順の文脈) | パース | バイナリ仕様・データモデル記述では「パースペクティブフラグ」が正 |
| カメラキー格納値としての「回転」 | 角度 | 補間チャンネル名の「回転」、回転行列・回転ノイズ等の一般用語は可 |
| 条件記述での「変更した」「変化する」等の基準点が不明瞭な語 | 観測可能な性質(「値が2種類以上ある」等) | 条件・手順以外の文脈は可 |

## 手順

1. Agentツールでサブエージェントを起動する:
   - `model: "haiku"`
   - プロンプトに、対象ファイル一覧・チェック項目(上記の表を含める)・出力形式を指定する
   - 出力形式: `ファイルパス:行番号 | 検出内容 | 該当規則` のリスト。検出ゼロの項目もその旨を報告
   - 禁止事項: ファイルの修正・作成・削除(読み取りとgrepのみ)
2. メインモデルは返ってきた候補を例外規則と文脈で精査し、
   「修正すべきもの/例外に該当するもの」に仕分けてユーザーに報告する
3. 修正はユーザーの指示があるまで行わない
