# コミット(Haiku委譲)

コミット作業はコストの安いHaikuサブエージェントに委譲する。メインモデルは対象の特定と結果確認のみ行う。

## 手順

1. `git status --short` で現在の状態を確認し、ユーザーの指示からコミット対象ファイルを特定する。対象が曖昧な場合は実行前にユーザーに確認する
2. Agentツールでサブエージェントを起動する:
   - `model: "haiku"`
   - プロンプトに以下を必ず含める:
     - 作業ディレクトリ(リポジトリルートの絶対パス)
     - ステージするファイルの明示的なリスト(`git add <files>` の形。`git add -A` や `git add .` は使わない)
     - コミットメッセージ本文(ユーザー指定があればそれを使用。なければメインモデル側で起草して渡す)
     - メッセージ末尾に空行を挟んで `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>` を付けること
     - コミット後に `git log --oneline -1` と `git status --short` を出力して報告すること
     - 禁止事項: `--amend`・`push`・`rebase`・指定外ファイルのステージ・`rm -rf`
3. エージェントの報告からコミットハッシュと残りの作業ツリー状態を確認し、ユーザーに報告する

## 対象外

`--amend` や rebase など履歴の書き換えを伴う操作はこのスキルの対象外。メインモデルがユーザーに確認した上で直接行う。
