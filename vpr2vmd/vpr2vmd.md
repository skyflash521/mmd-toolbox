# vpr2vmd 要求仕様書

VOCALOID プロジェクトファイル(vpr)から、標準口モーフ(あ・い・う・え・お)による口パクVMDを
生成する独立CLIツールの要求仕様。

---

## 1. 位置づけ

### 1.1 結論

本機能は `vpr2vmd` という独立CLIツールとして提供する。

`vpr2vmd` は、vpr を入力に、音符・音素・休符から口形イベント列と開き量を作って共有モジュール `lipsync`
に渡し、口パクVMDを **1コマンド**で出力する。

```text
入力 vpr(VOCALOIDプロジェクト)
  -> vpr2vmd(vpr_io 解析 → 口形イベント列＋開き量 → lipsync)
  -> 口パクVMD
  -> MMD/MMMで確認・編集
```

### 1.2 設計境界

CLAUDE.md の設計境界に従う。

- **vpr の解析**は共有の形式I/Oモジュール [vpr_io](../vpr_io/vpr_io.md) に委譲する。`vpr2vmd` は vpr のバイナリ/
  直列化構造を直接扱わない。
- **アニメ的口パクのキーフレーム生成**は共有ドメインモジュール [lipsync](../lipsync/lipsync.md) に委譲する
  (品質基準・母音合成・保持・協調調音・疎キー配置等)。
- **`vpr2vmd` 固有**: vpr の音符・音素・休符から口形イベント列を確定すること、vpr の強弱(ベロシティ/
  ダイナミクス)から開き量を決めること、CLI引数・プリセットの具体値。

### 1.3 独立ツールとする理由

- 入力が vpr(VOCALOIDプロジェクト)で、音声を入力に取る他ツールとは系統が異なる。vpr の解析は `vpr_io`、
  口パク生成は `lipsync` に委譲し、`vpr2vmd` 自体は両者を束ねて vpr 固有の入口処理(口形イベント確定・
  開き量)を担う薄いCLIとする。
- **音声認識を要さない**: vpr は母音・音素・時刻・休符が既知のため、認識誤差の無い口形イベント入力で
  `lipsync` のモーフ品質を駆動できる。

---

## 2. 目的

- vpr から、**認識誤差の無い口形イベント入力**でアニメ的(MMD的)な口パクを自動生成する。
- 口パクに必要な「時刻ごとの口形(母音)と開き量」を vpr から決定論的に作る。vpr の音符・休符・音素から
  母音・両唇閉鎖・無音を直接得るため、音声のRMSに基づく無音/閉口判定は不要(vpr では音符の有無で休符が
  分かる)。
- ピッチ(音高)は口パクに不要なため使わない。

### 2.1 非目標

- 口モーフ(あ・い・う・え・お、必要に応じ閉口)以外の表情は生成しない。
- vpr の歌唱表現(ピッチ・ビブラート等)の再現は対象外。口パク(口形と開き量)に限る。

---

## 3. 処理パイプライン

```text
入力 vpr
  ├─ vpr_io 解析            vpr_io → 音符(時刻・ピッチ・歌詞・音素・強弱)・休符・テンポ
  ├─ 口形イベント列の確定   vpr2vmd側 → 音素→母音(a/i/u/e/o)・両唇閉鎖、休符→無音。時刻はテンポから秒/フレームへ
  ├─ 開き量                 vpr2vmd側 → vpr の強弱(ベロシティ/ダイナミクス)→開き量(無ければ既定)
  └─ モーフ生成             lipsync(共有)+ mmd_toolbox → あ・い・う・え・お の口パクVMD
```

- **口形イベント列の確定(vpr2vmd 入口)**: `vpr_io` が返す音符の音素から母音(a/i/u/e/o)と両唇閉鎖を、
  休符から無音を、決定論的に確定する。vpr のテンポ・拍子から時刻⇔フレームを変換する。確定した口形
  イベント列(母音・両唇閉鎖・無音)を `lipsync` の入力とする。
- **開き量(vpr2vmd 入口)**: vpr の音符の強弱(ベロシティ/ダイナミクス)を各モーラの開き量へ写像する
  (強弱が無ければ既定の開き量)。これを `lipsync` の開き量入力とする。
- **モーフ生成**: `lipsync` が口形イベント列(各モーラの開き量を同梱)と生成パラメータからアニメ的口パクの
  モーフキーを生成する。VMD出力は `mmd_toolbox.vmd.io`。

音素→母音/両唇閉鎖の写像は `vpr2vmd` の固有処理(vpr の音素体系に対する判断)として置く。

---

## 4. コマンドライン仕様

### 4.1 書式

```text
vpr2vmd INPUT [options]
```

`INPUT` は vpr ファイル。既定出力は `<入力名>.vmd`。

### 4.2 主なオプション(初期案)

| 引数 | 既定 | 説明 |
|---|---:|---|
| `INPUT` | 必須 | 入力 vpr ファイル |
| `-o, --output PATH` | `<入力名>.vmd` | 出力VMD |
| `--overwrite` | off | 既存出力の上書きを許可 |
| `--model-name NAME` | 空 | VMDに格納するモデル名(最大20バイト, Shift-JIS) |
| `--style NAME` | プリセット名 | 口パクスタイルプリセット。`lipsync` の生成パラメータ(開き量レンジ・タイミング・誇張)を切り替える |
| `--open-max V` | プリセット値 | 口の開き量の上限 |
| `--default-open V` | プリセット値 | vpr に強弱が無いときの既定開き量 |
| `--report-json PATH` | なし | 音符・口形イベント・開き量・キー数の処理統計を出力 |
| `--dry-run` | off | 出力せず処理計画と診断を表示 |

CLIには口パクの「効かせ方」(プリセット選択と上限)を置く。`lipsync` の各生成パラメータの意味は
[lipsync.md](../lipsync/lipsync.md) を正本とし、本書では重複定義しない。

---

## 5. 入出力要件

- 出力VMDの書き出しは `mmd_toolbox.vmd.io` に委譲する。生成するのはモーフキーのみ。
- ボーン・カメラ・照明・セルフ影セクションは空で出力する。
- 文字列(モーフ名・モデル名)はShift-JIS(cp932)で格納する。
- 時間軸は30fps基準(`mmd_toolbox` 規約)。vpr のテンポに基づく時刻を30fpsフレームへ変換する。

---

## 6. mmd_toolbox・lipsync・vpr_io との関係

- vpr の解析は `vpr_io`、アニメ的口パクのキーフレーム生成は `lipsync`、VMDのモーフキー書き出しは
  `mmd_toolbox.vmd.io`。`vpr2vmd` はこれらを束ね、vpr 固有の入口処理(口形イベント確定・開き量)を担う。
- モーフキーがキー間で線形評価される事実は [vmd-interp.md](../mmd_toolbox/vmd-interp.md) が正本。
- **時間軸の変換**: `vpr_io` は vpr の時間表現(tick/拍)とテンポ・拍子を正規化して渡す。秒/30fpsフレームへの
  変換は `vpr2vmd` 入口で行う。
